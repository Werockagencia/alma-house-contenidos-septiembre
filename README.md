## Editar

Los guiones viven en `piezas/<reel>/guion.md` y el calendario en `scripts/plan.mjs`. Después de editar:

```bash
npm run site   # regenera index.html y CAPTIONS.md
```

El capítulo III (Nº 00–06) queda en el historial de Git.
